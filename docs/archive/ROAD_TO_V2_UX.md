# Road to v2: UX Direction (retired Swift app)

Summary: a UX proposal for the retired Swift app, drawing on the Envion Pure Data ecosystem. It argued for a single conceptual atom (the recursive feedback loop), named stages instead of generic nodes, a library of factory topologies, a canvas/matrix toggle, an envelope panel, a flat perform layout, and a deliberately slow, restrained UI. The original Spanish body was removed during the English-only cleanup; see the git history for the full text.
